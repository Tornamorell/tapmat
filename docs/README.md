# Documentación de Tapmat

Punto de entrada para personas y agentes. Léelo antes de tocar el código. **Si cambias algo que
estos documentos describen, actualízalos en el mismo cambio.**

| Documento                            | Para qué sirve                                                                                      |
| ------------------------------------ | --------------------------------------------------------------------------------------------------- |
| [`architecture.md`](architecture.md) | Piezas, rutas, reglas que no hay que romper, desarrollo local y despliegue.                         |
| [`data-model.md`](data-model.md)     | Tablas y reglas de negocio: montones, valor, snapshots.                                             |
| [`data-sources.md`](data-sources.md) | Scryfall y TCGdex (verificados) y la situación del deporte.                                         |
| [`design.md`](design.md)             | Identidad visual: concepto, paleta y su significado, tipografía, piezas.                            |
| [`scanner.md`](scanner.md)           | Cómo funciona el escáner, qué lee de cada tipo de carta, parámetros de ajuste y resultados medidos. |
| [`decisions.md`](decisions.md)       | Qué se decidió, por qué, qué se descartó y cuándo revisarlo. **Todo es provisional.**               |
| [`roadmap.md`](roadmap.md)           | Dónde está el proyecto, qué está hecho, qué falta y en qué orden.                                   |

Las pautas para agentes (convenciones y comandos) están en [`../AGENTS.md`](../AGENTS.md).
